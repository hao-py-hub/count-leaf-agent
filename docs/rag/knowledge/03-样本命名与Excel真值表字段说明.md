# 样本命名与 Excel 真值表字段说明

- **来源：** 课题组内部考种数据表与农业行业试验记载规范
- **版本：** V1.0
- **适用范围：** 油菜考种样本编号、照片命名与真值表字段
- **最后更新：** 2026-08-19
- **确认状态：** 待项目所有者确认后导入本机知识库

## 样本与照片命名

统一样本编号：`年份_地点_品种编号_重复号_株号`，例如 `2026_Wuhan_ZS11_R1_P03`。

- 年份：四位数字，例如 `2026`。
- 地点：试验地点拼音缩写，例如 `Wuhan`、`Changsha`。
- 品种编号：全称缩写或统一编号，例如 `ZS11`，须在全库唯一。
- 重复号：`R` 加数字，例如 `R1`。
- 株号：`P` 加两位数字，例如 `P03`。

同一植株多视角图片在样本编号后追加序号：主视图 `_1.jpg`、侧视图 `_2.jpg`、局部特写 `_3.jpg`。

## 真值表字段

| 字段 | 规则 |
| --- | --- |
| `N0` | 从 1 开始的行序号或样本唯一 ID。 |
| 年份、地点、重复、品种 | 按试验设计填写。 |
| 照片号 | 不含扩展名，必须与图片文件名一一对应。 |
| 主枝角果、分枝角果、总数 | 人工有效角果计数；总数为前两项之和。 |
| 一次有效分枝数 | 主茎上的有效分枝数量，整数。 |
| 株高 | 单位 cm，保留一位小数。 |
| 备注 | 记录残缺、开裂、病虫害等异常。 |

## 填写规范

1. Excel 一行对应一株，照片号不可重名、漏名或与文件名不一致。
2. 计数类字段为整数，长度类字段保留一位小数。
3. 缺失值统一填 `NA`，不得留空；异常样本必须在备注中说明。
4. 人工复核后保存新版本文件，文件名带版本号和日期，禁止覆盖原始真值表。

## 项目兼容性待确认

旧数据集可能使用 `N0.1.1.1` 等点分格式，而本规范使用下划线格式。导入或批量评测前必须确定映射/迁移规则，不得把两种格式当作同一文件名直接匹配。
